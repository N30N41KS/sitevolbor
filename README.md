# Sitevolbor — Информационный веб-ресурс

Адаптивный многостраничный веб-сайт с тематическим оформлением и семантической разметкой.

## Особенности
* Адаптивная верстка под десктопные и мобильные устройства.
* Чистая семантическая структура HTML5.
* Пользовательская стилизация интерфейса на CSS3.

## Стек технологий
* HTML5
* CSS3
* JavaScript
